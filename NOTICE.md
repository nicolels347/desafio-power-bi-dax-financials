# Aviso sobre os dados de exemplo

Este projeto usa o workbook Financial Sample disponibilizado pela Microsoft para fins de demonstração do Power BI. A Microsoft informa que os dados e workbooks são fornecidos como estão e que os dados pertencem à obviEnce, LLC. A amostra é fictícia e deve ser usada apenas para aprendizado e demonstração.

Fonte: https://learn.microsoft.com/en-us/power-bi/create-reports/sample-financial-download
